# 中日双语对照解释（按出现顺序）

## 1. 半个小时后 == 30分後（さんじゅっぷんご）
- **词汇：**
  - `30分後`（N5）"半小时后"（基本时间表达）
  - `盗掘穴`（とうくつあな）（N2）"盗洞"（专业词汇）

## 2. 盗洞已经打的见不到底了 == 盗掘穴はもう底が見えないほど深くなっていた
- **语法：**
  - `～ほど～ない`（N4）"到...的程度"
    - 例：`底が見えないほど`（深到看不见底）
- **词汇：**
  - `底`（そこ）（N5）"底部"
  - `見える`（みえる）（N5）"能看见"
  - `深い`（ふかい）（N5）"深的"

## 3. 除了老二不时上来透气 == 次男が時々息継ぎに上がってくる以外は
- **语法：**
  - `～以外は`（いがいは）（N4）"除了..."
  - `時々`（ときどき）（N5）"不时"
- **词汇：**
  - `次男`（じなん）（N3）"老二"
  - `息継ぎ`（いきつぎ）（N3）"透气"
  - `上がる`（あがる）（N5）"上来"

## 4. 洞里连声音都听不清楚了 == 穴の中からは声さえはっきり聞こえなかった
- **语法：**
  - `～さえ～ない`（N4）"连...都不..."
    - 例：`声さえ聞こえない`（连声音都听不见）
- **词汇：**
  - `声`（こえ）（N5）"声音"
  - `はっきり`（N5）"清楚"
  - `聞こえる`（きこえる）（N5）"能听见"

## 5. 老三等的不耐烦起来 == 三男は待ちくたびれて
- **词汇：**
  - `三男`（さんなん）（N3）"老三"
  - `待ちくたびれる`（まちくたびれる）（N3）"等得不耐烦"

## 6. 就朝洞里大叫 == 穴に向かって叫んだ
- **语法：**
  - `～に向かって`（～にむかって）（N4）"朝...方向"
- **词汇：**
  - `叫ぶ`（さけぶ）（N5）"大叫"

## 7. "大爷爷，挖穿没有喃？" == 「おい、爺さん、掘り抜けたか？」
- **词汇：**
  - `おい`（N5）"喂"（招呼语气）
  - `爺さん`（じいさん）（N5）"老爷子"
  - `掘り抜ける`（ほりぬける）（N3）"挖穿"
  - `か`（N5）"吗"（疑问词）
