# 中日双语对照解释 (N5重点版)

## 原文
果然，这样一来他就和洞里的东西对持住了，双方都各自吃力，但是都拉不动分毫，僵持了有10几秒，就听到洞里一声盒子炮响，然后听到他爹大叫："三伢子，快跑！！！！！！"，就觉的绳子一松，土耗子嗖一声从洞里弹了出来，好象上面还挂了什么东西！那时候老三也顾不得那么多了，一把接住土耗子扭头就跑！

## 日语翻译
案の定、これで彼は穴の中のものと対等に張り合うことになった。両方とも力を入れたが、全く動かなかった。10秒ほどこうしていたら、穴の中から拳銃の音がして、父親が『三男、逃げろ！！！』と叫ぶのが聞こえた。するとロープが緩んで、土鼠がヒューッと穴から飛び出してきた。何かがぶら下がっているようだった！その時三男はもう考える余裕もなく、土鼠を受け止めると振り向きざまに走り出した！

## 逐句解析 (N5重点)

### 1. "果然" == 案の定（あんのじょう）
- **词汇**：
  - `案の定`（N4）但常用可先记
- **近义N5词**：
  - `やはり`（N5）"果然"

### 2. "对持住了" == 張り合うことになった
- **词汇**：
  - `張り合う`（はりあう）（N4）
- **N5替代**：
  - `頑張る`（がんばる）（N5）"坚持"

### 3. "拉不动" == 動かない
- **词汇**：
  - `動く`（うごく）（N5）"移动"
- **语法**：
  - ない形（N5）否定

### 4. "10几秒" == 10秒ほど
- **数字表达**：
  - `10秒`（じゅうびょう）（N5）
  - `ほど`（N5）"大约"

### 5. "快跑" == 「逃げろ」
- **词汇**：
  - `逃げる`（にげる）（N5）"逃跑"
- **语法**：
  - 命令形`逃げろ`（N5变形）

### 6. "绳子一松" == ロープが緩んで
- **词汇**：
  - `緩む`（ゆるむ）（N4）
- **N5替代**：
  - `軽くなる`（かるくなる）（N5）"变轻"

### 7. "嗖一声" == ヒュ(hyu)ーッと
- **拟声词**：
  - 类似N5的`ドン`（咚）

### 8. "扭头就跑" == 振り向きざまに走り出した
- **N5可理解部分**：
  - `走る`（はしる）（N5）"跑"
  - `振り向く`（ふりむく）（N5）"回头看"

## N5重点语法复习

| 语法 | 例句 | 说明 |
|------|------|------|
| ない形 | 動かない | 否定形式 |
| 命令形 | 走れ！ | 紧急指令 |
| ほど | 10分ほど | 大约时间 |

## 文化小知识
1. 拟声词特点：
   - `ヒューッ`形容快速移动声
   - 类似中文"嗖"

2. 紧急表达：
   - 日语中多用命令形
   - `逃げろ`比`逃げてください`更紧急

## 学习建议
✅ 先掌握N5基础动词：
   - 動く
   - 逃げる
   - 走る

✅ 重点记忆：
   - 数字+時間单位（10秒）
   - 基本命令形（見る→見ろ）

✅ 拟声词：
   - 先记最基础的`ドン`（咚）、`ガタン`（哐当）
