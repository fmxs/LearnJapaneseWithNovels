# 面试复盘
在休息室等了一会，hr通知挂了，听到残念突然就蒙了，感觉被打击到了，觉得不至于会挂的。

分析了一下原因:

1. coding test 没给最优解
2. 日语不好，英语有的地方也没太表达明白，面试官可能觉得沟通不顺畅
3. 可能没考虑过怎么用英语回答问题。几个问题都没有答出自己的优势，加密方式和安全方面的考虑；
4. 最擅长的语言还是要说一门比较好，这个我后面会详细讲。
   此后准备面试期间，看了一下go的一些GC、goroutines、内存分配等相对底层的原理。
   后来的面试官再问我这个问题我就说go，然后show一下之前看到的技术细节（自我认为LINE的一面就是这样拿下的），
   面试官可能想通过这个问题看到你的深度，但现在想来这却是很好准备的。

由于一面就挂了回家了，所以不太清楚二面就是终面还是之后还有三面，总之这部分无法提供更多信息了。
