# 中日双语对照详解

## 原文
胡国华拼命的摇头，问那纸人你到底是妖还是鬼？白纸人说我当然是鬼，只是暂时附在这纸人身上，不过你个穷棒子还别嫌弃我，我生前很富有，陪葬的金银首饰够你抽十辈子大烟的，你岂不闻富死鬼强似穷命人百倍？

## 日语翻译
胡国華は必死に首を振り、「お前は結局のところ妖怪なのか、幽霊なのか？」と紙人形に問いただした。白紙の人形は「私はもちろん幽霊さ。ただ一時的にこの紙人形に憑依しているだけだ。だがこの貧乏人が私を嫌うなんてとんでもない。生前は大金持ちで、副葬品の金銀細工があれば、お前が十人生きても吸い切れないほどの阿片が買える。『金持ちの死霊は貧乏人の百倍まし』という言葉を知らないのか？」と答えた。

## 逐句解析

### 1. "拼命的摇头" == 「必死に首を振り」
- **结构分析**：
  - [语法] ～に（程度副词） → [词汇] 必死（ひっし/N3，拼命）
  - [语法] ～を振る（动作对象） → [词汇] 首（くび/N5，头）

### 2. "你到底是妖还是鬼" == 「お前は結局のところ妖怪なのか、幽霊なのか」
- **结构分析**：
  - [语法] ～なのか（疑问强调） → [词汇] 妖怪（ようかい/N3，妖怪）
  - [语法] 選択疑問 → [词汇] 幽霊（ゆうれい/N4，鬼魂）

### 3. "暂时附在这纸人身上" == 「一時的にこの紙人形に憑依しているだけ」
- **结构分析**：
  - [语法] ～に憑依する（附着表达） → [词汇] 一時的（いちじてき/N3，暂时）
  - [语法] ～だけ（限定） → [词汇] 憑依（ひょうい/N2，附身）

### 4. "陪葬的金银首饰" == 「副葬品の金銀細工」
- **结构分析**：
  - [语法] の（所属） → [词汇] 副葬品（ふくそうひん/N2，陪葬品）
  - [语法] 复合名词 → [词汇] 金銀細工（きんぎんざいく/N2，金银首饰）

### 5. "富死鬼强似穷命人百倍" == 「金持ちの死霊は貧乏人の百倍まし」
- **结构分析**：
  - [语法] ～は～まし（比较表达） → [词汇] 死霊（しりょう/N2，死灵）
  - [语法] 数量比较 → [词汇] 百倍（ひゃくばい/N3，百倍）
