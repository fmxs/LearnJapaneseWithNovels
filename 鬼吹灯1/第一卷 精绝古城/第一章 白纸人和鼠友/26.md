# 中日双语对照详解

## 原文
后来有几次穷得实在没办法了，就想去十三里铺挖坟，但是到最后还是忍住了，东借西凑的把日子混了下来。两年以后他山穷水尽走投无路终于去了那片坟地，不过那是后话，咱们暂且不表。

## 日语翻译
その後何度か貧困のあまり十三里舗の墓を掘り起こそうと思ったが、結局は我慢して、あちこちから借りるなどしてどうにか暮らしていた。二年後、途方に暮れた彼はついにあの墓場へと足を運んだが、それは後の話なので、ここではひとまず触れないでおこう。

---

## 逐句解析

### 1. "穷得实在没办法" == 「貧困のあまり」
- **结构分析**：
  - [语法] ～のあまり（程度过度） → [词汇] 貧困（ひんこん/N3，贫困）
  - [语法] 名词修饰 → [词汇] あまり（N4，过度）

### 2. "想去挖坟" == 「墓を掘り起こそうと思った」
- **结构分析**：
  - [语法] ～ようと思う（意志表达） → [词汇] 掘り起こす（ほりおこす/N3，挖掘）
  - [语法] ～を（动作对象） → [词汇] 墓（はか/N4，坟墓）

### 3. "东借西凑" == 「あちこちから借りるなどして」
- **结构分析**：
  - [语法] など（举例） → [词汇] あちこち（N4，各处）
  - [语法] ～て（手段表达） → [词汇] 借りる（かりる/N5，借）

### 4. "山穷水尽走投无路" == 「途方に暮れた」
- **结构分析**：
  - [语法] 惯用表达 → [词汇] 途方（とほう/N2，方法）
  - [语法] ～暮れる（复合动词） → [词汇] 暮れる（くれる/N5，陷入）

### 5. "暂且不表" == 「ひとまず触れないでおこう」
- **结构分析**：
  - [语法] ～ておく（放置表达） → [词汇] 触れる（ふれる/N4，提及）
  - [语法] ～よう（意志形） → [词汇] ひとまず（N3，暂且）

## 叙事手法注释
1. 时间跨度的处理：
   - 「二年後」的简洁过渡
   - 中文"后话"的日译处理

2. 贫困描写的层次：
   - 「貧困のあまり」的递进表达
   - 与之前情节的呼应
