# 中日双语对照详解

## 原文
说完，白纸人就一动不动了，胡国华壮着胆子，点了把火将白纸人烧成了灰烬。

## 日语翻译
そう言い終わると、白紙の人形は再び微動だにしなくなった。胡国華は勇気を奮い起こし、火をつけて白紙の人形を灰燼（かいじん）に帰した。

---

## 逐句解析

### 1. "一动不动" == 「微動だにしなくなった」
- **结构分析**：
  - [语法] ～だにしない（彻底否定） → [词汇] 微動（びどう/N1，微动）
  - [语法] ～なる（状态变化） → [词汇] しなく（N5，做[否定形]）

### 2. "壮着胆子" == 「勇気を奮い起こし」
- **结构分析**：
  - [语法] ～を（动作对象） → [词汇] 奮い起こす（ふるいおこす/N2，鼓起）
  - [语法] 复合动词 → [词汇] 勇気（ゆうき/N4，勇气）

### 3. "点了把火" == 「火をつけて」
- **结构分析**：
  - [语法] ～て（手段表达） → [词汇] 火（ひ/N5，火）
  - [语法] 动词连用形 → [词汇] つける（N5，点燃）

### 4. "烧成了灰烬" == 「灰燼に帰した」
- **结构分析**：
  - [语法] ～に帰する（文语表达） → [词汇] 灰燼（かいじん/N1，灰烬）
  - [语法] ～た（过去形） → [词汇] 帰する（きする/N1，归于）
