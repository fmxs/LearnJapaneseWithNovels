# 中日双语对照详解

## 原文
人要穷疯了，廉耻道德这些观念就不重要了，胡国华想了个办法，去找舅舅骗点钱。胡国华的舅舅知道他是败家子大烟鬼，平时一文钱都不肯给他，但是这次胡国华骗舅舅说要娶媳妇，让舅舅给凑点钱。

## 日语翻译
人間、貧乏のあまり正気を失うと、恥や道徳といった観念はどうでもよくなる。胡国華は一計を案じ、叔父を騙して金をせしめようと考えた。胡国華の叔父は、彼が道楽者の阿片中毒者だと知っており、普段は一銭も渡そうとしないが、今回は嫁をもらうと偽り、叔父に金を工面させようとしたのだ。

---

## 逐句解析

### 1. "人要穷疯了" == 「人間、貧乏のあまり正気を失うと」
- **结构分析**：
  - [语法] ～のあまり（程度过度） → [词汇] 貧乏（びんぼう/N4，贫穷）
  - [语法] ～と（条件表达） → [词汇] 正気（しょうき/N3，理智）

### 2. "廉耻道德这些观念就不重要了" == 「恥や道徳といった観念はどうでもよくなる」
- **结构分析**：
  - [语法] ～といった（列举代表） → [词汇] 恥（はじ/N3，羞耻）
  - [语法] ～なる（状态变化） → [词汇] 観念（かんねん/N3，观念）

### 3. "胡国华想了个办法" == 「胡国華は一計を案じ」
- **结构分析**：
  - [语法] ～を案じる（思考动作） → [词汇] 一計（いっけい/N2，计策）

### 4. "去找舅舅骗点钱" == 「叔父を騙して金をせしめようと考えた」
- **结构分析**：
  - [语法] ～ようとする（意图表达） → [词汇] 騙す（だます/N3，欺骗）
  - [语法] ～て（手段表达） → [词汇] せしめる（N2，骗取）

### 5. "知道他是败家子大烟鬼" == 「彼が道楽者の阿片中毒者だと知っており」
- **结构分析**：
  - [语法] ～だと（引用内容） → [词汇] 道楽者（どうらくもの/N3，败家子）
  - [语法] ～ており（持续状态） → [词汇] 中毒者（ちゅうどくしゃ/N3，上瘾者）

### 6. "骗舅舅说要娶媳妇" == 「嫁をもらうと偽り」
- **结构分析**：
  - [语法] ～と（引用内容） → [词汇] 嫁（よめ/N4，媳妇）
  - [语法] ～偽る（虚假表达） → [词汇] 偽る（いつわる/N2，欺骗）

## 社会伦理注释
1. 骗婚行为的社会背景：
   - 反映旧社会婚姻的经济属性
   - 体现鸦片瘾者的生存困境

2. 亲属关系的特殊性：
   - 「叔父」在家族中的地位
   - 传统家族的经济责任
