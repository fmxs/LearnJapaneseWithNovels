# 中日双语对照详解

## 原文
一提到钱胡国华就有些心动，因为最近实在太穷了，就连衣服都给当光了，不过他可不想有命取财无命花钱，他曾经听老人们讲起过女鬼勾汉子的事，一来二去就把男人的阳气吸光了，那些被鬼缠上的男人，最后都只剩下一副干皮包着的骨头架子。于是他对纸人说："就算是你真心对我好，我也不能娶你，毕竟咱们是人鬼殊途，阴阳阻隔，这样做有违天道。"

## 日语翻译
金の話になると胡国華は少し心が揺らぎ始めた。最近は本当に貧乏で、着る物さえ質に入れてしまったからだ。しかし、金は手に入れても命がなければ使えない。昔老人たちから聞いたことがある、女幽霊が男を誘惑し、次第に男の陽気を吸い取り、幽霊に取り憑かれた男たちは最後には皮一枚被った骸骨になるだけだと。そこで彼は紙人形にこう言った。「たとえあなたが本気で私を思ってくれていても、娶ることはできません。所詮私たちは人と幽霊、陰陽の隔たりがあり、これは天道に背く行為ですから」

## 逐句解析

### 1. "一提到钱就有些心动" == 「金の話になると少し心が揺らぎ始めた」
- **结构分析**：
  - [语法] ～になると（条件变化） → [词汇] 揺らぐ（ゆらぐ/N3，动摇）
  - [语法] ～始める（动作开始） → [词汇] 心（こころ/N4，心思）

### 2. "衣服都给当光了" == 「着る物さえ質に入れてしまった」
- **结构分析**：
  - [语法] さえ（极端举例） → [词汇] 質に入れる（しちにいれる/N3，典当）
  - [语法] ～しまう（遗憾语气） → [词汇] 着る物（きるもの/N4，衣服）

### 3. "女鬼勾汉子的事" == 「女幽霊が男を誘惑し」
- **结构分析**：
  - [语法] ～が（主语标记） → [词汇] 誘惑（ゆうわく/N3，勾引）
  - [语法] ～を（动作对象） → [词汇] 幽霊（ゆうれい/N4，鬼魂）

### 4. "阳气吸光了" == 「陽気を吸い取り」
- **结构分析**：
  - [语法] ～を（动作对象） → [词汇] 陽気（ようき/N3，阳气）
  - [语法] 复合动词 → [词汇] 吸い取る（すいとる/N3，吸光）

### 5. "人鬼殊途，阴阳阻隔" == 「人と幽霊、陰陽の隔たり」
- **结构分析**：
  - [语法] 并列表达 → [词汇] 陰陽（いんよう/N2，阴阳）
  - [语法] の（所属） → [词汇] 隔たり（へだたり/N3，阻隔）

### 6. "有违天道" == 「天道に背く」
- **结构分析**：
  - [语法] ～に背く（违反表达） → [词汇] 天道（てんどう/N2，天道）
  - [语法] 动词终止形 → [词汇] 背く（そむく/N3，违背）
