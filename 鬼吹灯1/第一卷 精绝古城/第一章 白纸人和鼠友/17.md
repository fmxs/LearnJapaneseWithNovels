# 中日双语对照详解

## 原文
舅舅老眼昏花，也没觉得那女人有什么不对头，七八杯老酒下肚就喝得伶仃大醉，胡国华借了辆驴车，把他送回家中。

## 日语翻译
叔父は老眼で目がかすんでおり、女に何の不審も感じなかった。七、八杯の強い酒を飲んで泥酔し、胡国華はロバ車を借りて、彼を家まで送り届けた。

---

## 逐句解析

### 1. "老眼昏花" == 「老眼で目がかすんでおり」
- **结构分析**：
  - [语法] ～で（原因表达） → [词汇] 老眼（ろうがん/N2，老花眼）
  - [语法] ～ており（持续状态） → [词汇] かすむ（N3，模糊）

### 2. "七八杯老酒下肚" == 「七、八杯の強い酒を飲んで」
- **结构分析**：
  - [语法] 数量词修饰 → [词汇] 杯（はい/N5，杯）
  - [语法] ～を飲む（动作对象） → [词汇] 強い酒（つよいさけ/N4，烈酒）

### 3. "伶仃大醉" == 「泥酔し」
- **结构分析**：
  - [语法] ～し（动作并列） → [词汇] 泥酔（でいすい/N2，烂醉）

### 4. "借了辆驴车" == 「ロバ車を借りて」
- **结构分析**：
  - [语法] ～を借りる（动作对象） → [词汇] ロバ車（N3，驴车）
  - [语法] ～て（手段表达） → [词汇] 借りる（かりる/N5，借）

### 5. "送回家中" == 「家まで送り届けた」
- **结构分析**：
  - [语法] ～まで（移动终点） → [词汇] 送り届ける（おくりとどける/N3，送达）
  - [语法] ～た（过去形） → [词汇] 家（いえ/N5，家）
