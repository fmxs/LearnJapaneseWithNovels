# 中日双语对照详解

## 原文
胡国华一想留着她晚上再变成活人怎么办，不如我一把火烧了它干净。把白纸人抗到院子里，取出火摺子，就想动手烧了纸人，这时纸人忽然开口说话："你个死没良心的，我好心好意帮你，却想烧了我！"

## 日语翻译
胡国華は考えた。「このままにしておいて、夜また生き返ったらどうしよう。いっそ火をつけて焼き払ってしまおう」と。白紙の人形を庭に担ぎ出し、火打ち石を取り出すと、いざ人形を焼こうとしたその時、人形が突然口を開いた。「この恩知らずめ！ 私は善意でお前を助けてやったのに、焼き殺そうとするとは！」

---

## 逐句解析

### 1. "一把火烧了它干净" == 「火をつけて焼き払ってしまおう」
- **结构分析**：
  - [语法] ～てしまう（彻底完成） → [词汇] 焼き払う（やきはらう/N2，烧光）
  - [语法] ～う（意志形） → [词汇] 火をつける（ひをつける/N4，点火）

### 2. "抗到院子里" == 「庭に担ぎ出し」
- **结构分析**：
  - [语法] ～に（方向目标） → [词汇] 担ぎ出す（かつぎだす/N3，扛出去）
  - [语法] 庭（にわ/N5，院子）

### 3. "取出火摺子" == 「火打ち石を取り出す」
- **结构分析**：
  - [语法] ～を（动作对象） → [词汇] 火打ち石（ひうちいし/N3，火石）
  - [语法] 取り出す（とりだす/N4，取出）

### 4. "纸人忽然开口说话" == 「人形が突然口を開いた」
- **结构分析**：
  - [语法] ～が（主语标记） → [词汇] 口を開く（くちをひらく/N4，开口）
  - [语法] 突然（とつぜん/N3，突然）

### 5. "死没良心的" == 「恩知らずめ」
- **结构分析**：
  - [语法] 骂詈语め → [词汇] 恩知らず（おんしらず/N3，忘恩负义）
  - [语法] 名词化接尾 → [词汇] め（N4，[骂]家伙）

### 6. "好心好意帮你" == 「善意でお前を助けてやった」
- **结构分析**：
  - [语法] ～てやる（施惠表达） → [词汇] 善意（ぜんい/N3，好意）
  - [语法] ～で（手段限定） → [词汇] 助ける（たすける/N4，帮助）

## 超自然现象注释
1. 纸人说话的表现手法：
   - 「口を開く」的灵异感营造
   - 骂詈语「め」的情感强度

2. 火具的历史考据：
   - 「火打ち石」在民国的使用
   - 与「火摺子」的准确对应
