# 中日双语对照详解

## 原文
到了民国年间，传到我祖父这一代就开始家道中落了，先是分了家，胡国华也分到了不少家产，足够衣食无忧的过一辈子，可是他偏偏不肯学好，当然这也和当时的社会环境有关，先是沉迷赌博，后来又抽上了福寿膏（大烟），把万贯家财败了个精光。

## 日语翻译
民国時代になると、私の祖父の代で家運が傾き始めた。まず家財を分け、胡国華も相当な財産を相続し、一生食べるに困らないほどだった。しかし彼はまともな道を選ばず、これは当時の社会環境とも関係があったが、最初は賭博に溺れ、後に阿片（福寿膏）を吸うようになり、莫大な家財をすっかり使い果たしてしまった。

## 逐句解析

### 1. "到了民国年间" == 「民国時代になると」
- **结构分析**：
  - [语法] ～になると（时间变化标记） → [词汇] 民国時代（みんこくじだい/N2，民国时期）

### 2. "传到我祖父这一代就开始家道中落了" == 「私の祖父の代で家運が傾き始めた」
- **结构分析**：
  - [语法] ～の代で（表示世代） → [词汇] 代（だい/N3，世代）
  - [语法] ～が傾く（状态变化） → [词汇] 家運（かうん/N2，家运）

### 3. "先是分了家" == 「まず家財を分け」
- **结构分析**：
  - [语法] まず（顺序副词） → [词汇] 家財（かざい/N2，家产）
  - [语法] ～を分ける（动作对象） → [词汇] 分ける（わける/N4，分割）

### 4. "胡国华也分到了不少家产" == 「胡国華も相当な財産を相続し」
- **结构分析**：
  - [语法] も（强调助词） → [词汇] 財産（ざいさん/N3，财产）
  - [语法] ～を相続する（继承动作） → [词汇] 相続（そうぞく/N2，继承）

### 5. "足够衣食无忧的过一辈子" == 「一生食べるに困らないほどだった」
- **结构分析**：
  - [语法] ～に困らない（否定可能形） → [词汇] 食べる（たべる/N5，吃饭）
  - [语法] ほど（程度表达） → [词汇] 一生（いっしょう/N3，一辈子）

### 6. "可是他偏偏不肯学好" == 「しかし彼はまともな道を選ばず」
- **结构分析**：
  - [语法] ～を選ぶ（选择动作） → [词汇] 道（みち/N5，道路/道路）
  - [语法] ～ず（否定形） → [词汇] まとも（な/N3，正经的）

### 7. "先是沉迷赌博" == 「最初は賭博に溺れ」
- **结构分析**：
  - [语法] ～に溺れる（沉迷表达） → [词汇] 賭博（とばく/N1，赌博）

### 8. "后来又抽上了福寿膏" == 「後に阿片（福寿膏）を吸うようになり」
- **结构分析**：
  - [语法] ～ようになる（变化表达） → [词汇] 阿片（あへん/N1，鸦片）

### 9. "把万贯家财败了个精光" == 「莫大な家財をすっかり使い果たしてしまった」
- **结构分析**：
  - [语法] ～てしまう（完成体） → [词汇] 使い果たす（つかいはたす/N2，用尽）
