# 中日双语对照详解

## 原文
白纸人说你既然如此铁石心肠，我也不勉强你，不过将来早晚有你后悔的那一天。你记住了，如果你的日子真到了穷得过不下去的时候，你就到十三里铺的荒坟来找我，在那片坟地的最中间有座没有墓碑的孤坟，里面的棺材就是我尸身所在，棺中有得是金银珠宝，只要你敢来，那些财物就尽管随意拿去花用。

## 日语翻译
白紙の人形は言った。「ここまで鉄石の心なら、無理強いもしない。だが遅かれ早かれ後悔する日が来るだろう。よく覚えておけ。もし本当に生きていけなくなるほど貧しくなったら、十三里舗の無縁墓を訪ねて来い。あの墓場の真ん中に墓碑のない孤塚がある。中の棺桶が私の遺体の眠る場所だ。棺の中には金銀財宝がたっぷりある。来る勇気さえあれば、それらの財宝は自由に使ってよい」

---

## 逐句解析

### 1. "铁石心肠" == 「鉄石の心」
- **结构分析**：
  - [语法] の（属性连接） → [词汇] 鉄石（てっせき/N2，铁石）
  - [语法] 名词短语 → [词汇] 心（こころ/N4，心肠）

### 2. "荒坟" == 「無縁墓」
- **结构分析**：
  - [语法] 复合名词 → [词汇] 無縁（むえん/N2，无主）
  - [语法] 名词接续 → [词汇] 墓（はか/N4，坟墓）

### 3. "没有墓碑的孤坟" == 「墓碑のない孤塚」
- **结构分析**：
  - [语法] ～ない（否定形） → [词汇] 墓碑（ぼひ/N2，墓碑）
  - [语法] 名词修饰 → [词汇] 孤塚（こちょう/N1，孤坟）

### 4. "尸身所在" == 「遺体の眠る場所」
- **结构分析**：
  - [语法] の（主格） → [词汇] 眠る（ねむる/N5，安眠）
  - [语法] 动词连体形 → [词汇] 遺体（いたい/N3，尸身）

### 5. "尽管随意拿去花用" == 「自由に使ってよい」
- **结构分析**：
  - [语法] ～てよい（许可表达） → [词汇] 自由（じゆう/N5，随意）
  - [语法] 副词修饰 → [词汇] 使う（つかう/N5，使用）

## 冥界观念注释
1. 无主坟墓的特殊表达：
   - 「無縁墓」的佛教渊源
   - 中日对待孤坟的习俗差异

2. 财宝诱惑的描写：
   - 「たっぷり」的数量强调
   - 鬼魂财物的禁忌性
