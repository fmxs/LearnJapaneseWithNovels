# 中日双语对照详解

## 原文
于是给他拿了二十块大洋，嘱咐他娶个媳妇好好过日子，千万别再沾染那些福寿膏了，过几天得空，还要亲自去胡国华家看看外甥媳妇。

## 日语翻译
そこで叔父は銀貨二十枚を渡し、「嫁をもらってまともに暮らせよ。二度と阿片（福寿膏）に手を出すんじゃないぞ」と戒めた。数日後時間ができたら、胡国華の家まで直接会いに行って、甥の嫁を見届けるつもりだと言い添えた。

---

## 逐句解析

### 1. "于是给他拿了二十块大洋" == 「そこで叔父は銀貨二十枚を渡し」
- **结构分析**：
  - [语法] ～を渡す（动作对象） → [词汇] 銀貨（ぎんか/N2，银元）
  - [语法] 数量词直接修饰 → [词汇] 枚（まい/N5，计数单位）

### 2. "嘱咐他娶个媳妇好好过日子" == 「『嫁をもらってまともに暮らせよ』と戒めた」
- **结构分析**：
  - [语法] ～て（接续助词） → [词汇] 嫁（よめ/N4，媳妇）
  - [语法] 命令形～せよ → [词汇] 暮らす（くらす/N5，生活）

### 3. "千万别再沾染那些福寿膏了" == 「『二度と阿片（福寿膏）に手を出すんじゃないぞ』」
- **结构分析**：
  - [语法] ～に手を出す（惯用表达） → [词汇] 二度と（にどと/N3，再也不）
  - [语法] 禁止形～じゃないぞ → [词汇] 阿片（あへん/N1，鸦片）

### 4. "过几天得空" == 「数日後時間ができたら」
- **结构分析**：
  - [语法] ～たら（条件形） → [词汇] 数日後（すうじつご/N3，几天后）
  - [语法] ～ができる（可能形） → [词汇] 時間（じかん/N5，时间）

### 5. "还要亲自去胡国华家看看外甥媳妇" == 「胡国華の家まで直接会いに行って、甥の嫁を見届けるつもりだ」
- **结构分析**：
  - [语法] ～まで（范围限定） → [词汇] 直接（ちょくせつ/N3，亲自）
  - [语法] ～つもりだ（意图表达） → [词汇] 見届ける（みとどける/N2，确认）

## 社会文化注释
1. 货币单位的处理：
   - "大洋"译为「銀貨」保留历史感
   - 使用「枚」作为计数单位更符合日语习惯

2. 家庭监督的传统：
   - 叔父亲自查看反映旧式家族监督
   - 「見届ける」包含监督确认的含义
