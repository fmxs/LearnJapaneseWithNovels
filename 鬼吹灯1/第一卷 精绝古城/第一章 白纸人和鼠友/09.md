# 中日双语对照详解

## 原文
他按要求给胡国华扎了个白纸糊裱的纸女人，又用水彩给纸人画上了眉眼鼻子、衣服头发，在远处一看，嘿，真就跟个活人似的。

## 日语翻译
職人は注文通り胡国華のために白紙で貼り固めた女性の人形を作り、さらに水彩絵の具で目・眉・鼻・衣服・髪などを描き加えた。遠くから見ると、なんと、まるで生きている人間そっくりだった。

---

## 逐句解析

### 1. "按要求给胡国华扎了个白纸糊裱的纸女人" == 「職人は注文通り胡国華のために白紙で貼り固めた女性の人形を作り」
- **结构分析**：
  - [语法] ～通り（按照） → [词汇] 注文通り（ちゅうもんどおり/N3，按要求）
  - [语法] ～で（材料限定） → [词汇] 白紙（はくし/N3，白纸）
  - [语法] ～た（过去形） → [词汇] 貼り固める（はりかためる/N2，糊裱）

### 2. "又用水彩给纸人画上了眉眼鼻子、衣服头发" == 「さらに水彩絵の具で目・眉・鼻・衣服・髪などを描き加えた」
- **结构分析**：
  - [语法] ～で（工具限定） → [词汇] 水彩絵の具（すいさいえのぐ/N3，水彩颜料）
  - [语法] ～を描き加える（复合动词） → [词汇] 描き加える（かきくわえる/N2，添画）

### 3. "在远处一看" == 「遠くから見ると」
- **结构分析**：
  - [语法] ～から（视点起点） → [词汇] 遠く（とおく/N4，远处）
  - [语法] ～と（条件形） → [词汇] 見る（みる/N5，看）

### 4. "真就跟个活人似的" == 「まるで生きている人間そっくりだった」
- **结构分析**：
  - [语法] まるで～そっくり（比喻表达） → [词汇] 生きている（いきている/N5，活着的）
  - [语法] ～だった（过去形） → [词汇] 人間（にんげん/N5，人类）
