# 中日双语对照详解

## 原文
回去的路上，越想越觉得害怕，干脆也不回家了，去城里的花柳巷中过了一夜，连抽带嫖把舅舅刚给的十个大洋都使光了。

## 日语翻译
帰り道、考えれば考えるほど恐ろしくなり、思い切って家に帰らず、街の遊郭で一夜を過ごした。阿片を吸い女郎を買って、叔父からもらったばかりの銀貨十枚をすっかり使い果たしてしまった。

---

## 逐句解析

### 1. "越想越觉得害怕" == 「考えれば考えるほど恐ろしくなり」
- **结构分析**：
  - [语法] ～ば～ほど（越...越...） → [词汇] 恐ろしい（おそろしい/N4，可怕）
  - [语法] ～なり（变化结果） → [词汇] 考える（かんがえる/N5，思考）

### 2. "干脆也不回家了" == 「思い切って家に帰らず」
- **结构分析**：
  - [语法] ～て（手段表达） → [词汇] 思い切って（おもいきって/N3，干脆）
  - [语法] ～ず（否定形） → [词汇] 帰る（かえる/N5，回家）

### 3. "去城里的花柳巷中过了一夜" == 「街の遊郭で一夜を過ごした」
- **结构分析**：
  - [语法] ～で（场所限定） → [词汇] 遊郭（ゆうかく/N2，花柳巷）
  - [语法] ～を過ごす（动作对象） → [词汇] 一夜（いちや/N3，一夜）

### 4. "连抽带嫖" == 「阿片を吸い女郎を買って」
- **结构分析**：
  - [语法] ～を吸う（动作对象） → [词汇] 阿片（あへん/N1，鸦片）
  - [语法] ～を買う（动作对象） → [词汇] 女郎（じょろう/N2，妓女）

### 5. "十个大洋都使光了" == 「銀貨十枚をすっかり使い果たしてしまった」
- **结构分析**：
  - [语法] ～てしまう（完成体） → [词汇] 使い果たす（つかいはたす/N2，用尽）
  - [语法] すっかり（完全副词） → [词汇] 銀貨（ぎんか/N2，银元）

## 社会现象注释
1. 花柳巷的特殊译法：
   - 「遊郭」与中文"花柳巷"的对应关系
   - 日本游廓的历史背景

2. 成瘾行为模式：
   - 「吸い買って」的连用形表达
   - 快速挥霍的心理描写
