# 中日双语对照详解

## 原文
胡国华就死活拦着不让见，他越拦越显得有问题，舅舅更家疑心，两下里争执起来。正在此时，里屋门帘撩开了，出来一个女子，长得白白净净的，大脸盘子、大屁股小脚，胡国华心里咯噔一下，哎呦，这不就是我找人糊的纸人吗？它怎么活了？

## 日语翻译
胡国華は命がけで会わせまいと遮った。彼が遮れば遮るほど怪しまれ、叔父の疑念はますます深まり、二人は言い争いになった。ちょうどその時、奥の間の簾がサッと開き、色白で丸顔、大きなお尻に纏足（てんそく）をした女性が現れた。胡国華は胸がドキリとした。「あれ、あれは私が注文した紙人形じゃないか？ どうして生きているんだ？」

## 逐句解析

### 1. "死活拦着不让见" == 「命がけで会わせまいと遮った」
- **结构分析**：
  - [语法] ～まい（否定意志） → [词汇] 命がけ（いのちがけ/N3，拼死）
  - [语法] ～と（引用内容） → [词汇] 遮る（さえぎる/N3，阻拦）

### 2. "越拦越显得有问题" == 「遮れば遮るほど怪しまれ」
- **结构分析**：
  - [语法] ～ば～ほど（越...越...） → [词汇] 怪しむ（あやしむ/N2，怀疑）
  - [语法] 被动形～れ → [词汇] 遮る（さえぎる/N3，阻拦）

### 3. "两下里争执起来" == 「二人は言い争いになった」
- **结构分析**：
  - [语法] ～になる（状态变化） → [词汇] 言い争い（いいあらそい/N3，争执）
  - [语法] ～は（主题提示） → [词汇] 二人（ふたり/N5，两人）

### 4. "里屋门帘撩开了" == 「奥の間の簾がサッと開き」
- **结构分析**：
  - [语法] 拟态词サッと → [词汇] 簾（すだれ/N3，门帘）
  - [语法] ～が（主语标记） → [词汇] 開く（ひらく/N5，打开）

### 5. "大脸盘子、大屁股小脚" == 「丸顔、大きなお尻に纏足をした」
- **结构分析**：
  - [语法] ～に（附着点） → [词汇] 纏足（てんそく/N1，缠足）
  - [语法] 形容词连体形 → [词汇] 丸顔（まるがお/N3，圆脸）

### 6. "心里咯噔一下" == 「胸がドキリとした」
- **结构分析**：
  - [语法] 拟声词ドキリ → [词汇] 胸（むね/N4，心脏）
  - [语法] ～とする（瞬间动作） → [词汇] ドキリ（N3，咯噔）

### 7. "它怎么活了" == 「どうして生きているんだ」
- **结构分析**：
  - [语法] どうして（疑问词） → [词汇] 生きる（いきる/N5，活着）
  - [语法] ～んだ（解释说明） → [词汇] どうして（N5，为什么）

## 超自然现象注释
1. 纸人复活的象征：
   - 中日纸人偶的超自然信仰
   - 「簾がサッと開き」的灵异暗示

2. 缠足描写的处理：
   - 使用「纏足」专业术语
   - 保留中国封建习俗特征
