# 中日双语对照详解

## 原文
女人对舅舅施了一礼说近日身体不好，刚才没出来迎接舅舅，失礼之处还请恕罪，现在突然又觉得身子大好了，今天就留舅舅在家吃顿便饭，说完就转身进去做饭。

## 日语翻译
女性は叔父に丁寧にお辞儀をし、「このところ体調が優れず、さきほどは叔父様をお迎えできず、失礼いたしました。突然ですが、体調が回復いたしましたので、今日はぜひご自宅で粗飯でも召し上がっていってください」と言い、そう言い終わるとくるりと背を向けて台所へ入っていった。

---

## 逐句解析

### 1. "对舅舅施了一礼" == 「叔父に丁寧にお辞儀をし」
- **结构分析**：
  - [语法] ～に（对象标记） → [词汇] お辞儀（おじぎ/N4，行礼）
  - [语法] ～を（动作对象） → [词汇] 丁寧（ていねい/N4，恭敬）

### 2. "近日身体不好" == 「このところ体調が優れず」
- **结构分析**：
  - [语法] ～が（主语标记） → [词汇] 体調（たいちょう/N3，身体状况）
  - [语法] ～ず（否定形） → [词汇] 優れる（すぐれる/N2，良好）

### 3. "失礼之处还请恕罪" == 「失礼いたしました」
- **结构分析**：
  - [语法] 谦让语いたす → [词汇] 失礼（しつれい/N4，失礼）
  - [语法] ～ました（敬体过去形） → [词汇] いたす（N3，做[谦]）

### 4. "突然又觉得身子大好了" == 「突然ですが、体調が回復いたしました」
- **结构分析**：
  - [语法] ～が（转折） → [词汇] 回復（かいふく/N3，恢复）
  - [语法] 谦让语いたす → [词汇] 突然（とつぜん/N3，突然）

### 5. "留舅舅在家吃顿便饭" == 「ぜひご自宅で粗飯でも召し上がっていってください」
- **结构分析**：
  - [语法] 尊敬语召し上がる → [词汇] 粗飯（そはん/N2，便饭）
  - [语法] ～てください（请求形） → [词汇] ぜひ（N4，务必）

### 6. "转身进去做饭" == 「くるりと背を向けて台所へ入っていった」
- **结构分析**：
  - [语法] 拟态词くるりと → [词汇] 背を向ける（せをむける/N3，转身）
  - [语法] ～ていく（移动方向） → [词汇] 台所（だいどころ/N4，厨房）

## 礼仪行为注释
1. 谦让语的使用：
   - 「いたす」「申す」的恰当运用
   - 体现中国传统家庭礼仪

2. 待客之道：
   - 「粗飯」的自谦表达
   - 转身动作的文化含义
