# 中日双语对照详解

## 原文
胡国华把纸人扛到家里，放在里屋的炕上，用被子把纸人盖了，心里想的挺好，等过几天舅舅来了，就推说我媳妇病了，躺在床上不能见客，让他远远的看一眼就行了。想到得意处，忍不住哼起了小曲，溜哒进城抽大烟去了。

## 日语翻译
胡国華は紙人形を家まで担ぎ、奥の間の炕（かん）の上に置き、布団で覆い隠した。内心では「数日後に叔父が来たら、『嫁は病気で寝込んでおり、客に会えない』と言い訳して、遠くからちらりと見せるだけにしよう」とうまく考えていた。得意のあまり、思わず小唄を口ずさみながら、街へ出て阿片を吸いに行った。

## 逐句解析

### 1. "把纸人扛到家里" == 「紙人形を家まで担ぎ」
- **结构分析**：
  - [语法] ～まで（移动终点） → [词汇] 担ぐ（かつぐ/N3，扛）
  - [语法] ～を（动作对象） → [词汇] 紙人形（かみにんぎょう/N3，纸人）

### 2. "放在里屋的炕上" == 「奥の間の炕（かん）の上に置き」
- **结构分析**：
  - [语法] ～に（位置标记） → [词汇] 炕（かん/N1，炕）
  - [语法] ～を置く（动作对象） → [词汇] 奥の間（おくのま/N3，里屋）

### 3. "用被子把纸人盖了" == 「布団で覆い隠した」
- **结构分析**：
  - [语法] ～で（工具限定） → [词汇] 布団（ふとん/N4，被子）
  - [语法] ～隠す（复合动词） → [词汇] 覆う（おおう/N3，遮盖）

### 4. "等过几天舅舅来了" == 「数日後に叔父が来たら」
- **结构分析**：
  - [语法] ～たら（条件形） → [词汇] 数日後（すうじつご/N3，几天后）
  - [语法] ～が来る（自动词） → [词汇] 叔父（おじ/N4，舅舅）

### 5. "推说我媳妇病了" == 「『嫁は病気で寝込んでおり』と言い訳して」
- **结构分析**：
  - [语法] ～で（原因表达） → [词汇] 寝込む（ねこむ/N3，卧病）
  - [语法] ～と言い訳する → [词汇] 言い訳（いいわけ/N3，借口）

### 6. "忍不住哼起了小曲" == 「思わず小唄を口ずさみながら」
- **结构分析**：
  - [语法] ～ながら（伴随状态） → [词汇] 口ずさむ（くちずさむ/N2，哼唱）
  - [语法] 思わず（副词） → [词汇] 小唄（こうた/N3，小曲）

### 7. "溜哒进城抽大烟去了" == 「街へ出て阿片を吸いに行った」
- **结构分析**：
  - [语法] ～へ出る（移动表达） → [词汇] 街（まち/N4，城里）
  - [语法] ～に行く（目的表达） → [词汇] 阿片（あへん/N1，鸦片）
