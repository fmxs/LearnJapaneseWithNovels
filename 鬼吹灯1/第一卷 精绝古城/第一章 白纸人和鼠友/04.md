# 中日双语对照详解

## 原文
胡国华年轻的时候吃喝嫖赌抽五毒俱全，到最后穷得身上连一个大子儿都没有了。人要是犯了烟瘾，就抓心挠肝的无法忍受，但是没钱谁让你抽啊？昔日里有钱的时候，烟馆里的老板伙计见了他都是胡爷长，胡爷短的，招呼得殷勤周到，可是一但你身无分文了，他们就拿你当臭要饭的，连哄带赶，驱之不及。

## 日语翻译
胡国華は若い頃、飲む・打つ・買う・賭ける・吸うの五悪の道に溺れ、最後には一文無しの状態にまで落ちぶれた。阿片の禁断症状に襲われると、身を切られるような苦しみに耐えられなくなるが、金がなければ吸わせてもらえない。昔金があった頃は、阿片窟の主人も店員も「胡様」「胡旦那」と丁寧に呼び、慇懃に応対していたものだ。しかし一旦無一文になると、彼らは乞食同然に扱い、追い払おうとしてくるのだ。

## 逐句解析

### 1. "吃喝嫖赌抽五毒俱全" == 「飲む・打つ・買う・賭ける・吸うの五悪の道に溺れ」
- **结构分析**：
  - [语法] ～に溺れる（沉迷表达） → [词汇] 五悪（ごあく/N2，五毒）
  - [语法] ・（列举标记） → [词汇] 飲む（のむ/N5，喝）

### 2. "穷得身上连一个大子儿都没有了" == 「一文無しの状態にまで落ちぶれた」
- **结构分析**：
  - [语法] ～にまで（程度强调） → [词汇] 一文無し（いちもんなし/N3，身无分文）
  - [语法] ～た（过去形） → [词汇] 落ちぶれる（おちぶれる/N2，落魄）

### 3. "抓心挠肝的无法忍受" == 「身を切られるような苦しみに耐えられなくなる」
- **结构分析**：
  - [语法] ～ような（比喻表达） → [词汇] 苦しみ（くるしみ/N4，痛苦）
  - [语法] ～なくなる（否定变化） → [词汇] 耐える（たえる/N3，忍受）

### 4. "烟馆里的老板伙计见了他都是胡爷长，胡爷短的" == 「阿片窟の主人も店員も「胡様」「胡旦那」と丁寧に呼び」
- **结构分析**：
  - [语法] ～も～も（全面列举） → [词汇] 阿片窟（あへんくつ/N1，烟馆）
  - [语法] ～と（引用内容） → [词汇] 旦那（だんな/N3，老爷）

### 5. "拿你当臭要饭的，连哄带赶" == 「乞食同然に扱い、追い払おうとしてくる」
- **结构分析**：
  - [语法] ～同然（比喻表达） → [词汇] 乞食（こじき/N3，乞丐）
  - [语法] ～ようとする（意图表达） → [词汇] 追い払う（おいはらう/N3，驱赶）

## 社会现象注释
1. 称呼变化的社会意义：
   - 「胡様」→「乞食」的称呼转变
   - 反映旧社会人情冷暖

2. 五悪的日译处理：
   - 采用「飲む・打つ・買う・賭ける・吸う」具体化翻译
   - 保留中文"五毒"概念
