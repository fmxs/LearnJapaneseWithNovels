# 中日双语对照详解

## 原文
胡国华鬼主意最多，为了应付舅舅，他回家之后到村里找了个扎纸人纸马的匠人，就是烧给死人的那种。这个扎纸师傅手艺很高明，只要你说得出来的东西，他都能做的惟妙惟肖。

## 日语翻译
胡国華は悪知恵に長けており、叔父をごまかすため、家に帰ると村で紙人形や紙馬を作る職人を探した。これは死者に供えるあの紙細工のことだ。この紙細工職人は非常に腕が良く、注文さえすればどんなものでも生き写しに作ることができた。

## 逐句解析

### 1. "胡国华鬼主意最多" == 「胡国華は悪知恵に長けており」
- **结构分析**：
  - [语法] ～に長ける（擅长表达） → [词汇] 悪知恵（わるじえ/N3，鬼主意）
  - [语法] ～おり（持续状态） → [词汇] 長ける（たける/N2，擅长）

### 2. "为了应付舅舅" == 「叔父をごまかすため」
- **结构分析**：
  - [语法] ～ため（目的表达） → [词汇] ごまかす（N3，应付/欺骗）
  - [语法] ～を（对象格） → [词汇] 叔父（おじ/N4，舅舅）

### 3. "到村里找了个扎纸人纸马的匠人" == 「村で紙人形や紙馬を作る職人を探した」
- **结构分析**：
  - [语法] ～で（场所限定） → [词汇] 紙人形（かみにんぎょう/N3，纸人）
  - [语法] ～を作る（动作对象） → [词汇] 職人（しょくにん/N3，匠人）

### 4. "就是烧给死人的那种" == 「これは死者に供えるあの紙細工のことだ」
- **结构分析**：
  - [语法] ～に供える（供奉表达） → [词汇] 死者（ししゃ/N2，死者）
  - [语法] ～のことだ（说明表达） → [词汇] 紙細工（かみざいく/N3，纸工艺品）

### 5. "这个扎纸师傅手艺很高明" == 「この紙細工職人は非常に腕が良く」
- **结构分析**：
  - [语法] ～が良い（状态描述） → [词汇] 腕（うで/N4，手艺）
  - [语法] 非常に（程度副词） → [词汇] 職人（しょくにん/N3，工匠）

### 6. "只要你说得出来的东西" == 「注文さえすれば」
- **结构分析**：
  - [语法] ～さえ～ば（条件强调） → [词汇] 注文（ちゅうもん/N3，订单/要求）

### 7. "他都能做的惟妙惟肖" == 「どんなものでも生き写しに作ることができた」
- **结构分析**：
  - [语法] ～でも（全面肯定） → [词汇] 生き写し（いきうつし/N2，惟妙惟肖）
  - [语法] ～ことができる（可能形） → [词汇] 作る（つくる/N5，制作）

1. 纸扎工艺的特殊性：
   - 中日丧葬纸工艺的异同

   - 特殊工艺的师徒制度
