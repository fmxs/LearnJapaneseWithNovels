# 中日双语对照详解

## 原文
胡国华呆在当场，心里慌乱，也不知是该庆幸还是该害怕，时间过的很快，一转眼就到了晚上，白纸人做了一桌饭菜，舅舅乐得嘴都合不上了，但是胡国华却无心吃喝，他看着坐在自己对面的那个女人，就觉得心里跟吃了只苍蝇似的恶心。她的脸很白，一点血色没有，脸上的红润都是用胭脂抹上的。

## 日语翻译
胡国華はその場に呆然と立ち尽くし、心は混乱していた。喜ぶべきか恐れるべきか、自分でもわからない状態だった。時間はあっという間に過ぎ、気がつけば夜になっていた。白紙の人形が作った料理が食卓に並び、叔父は嬉しさのあまり口を閉じることができないほどだった。しかし胡国華は飲食する気になれず、向かい側に座っているあの女を見ると、まるで蝿を飲み込んだような嫌悪感に襲われた。彼女の顔は青白く、血の気が全くなく、頬の紅はすべて紅（べに）で塗られていた。

## 逐句解析

### 1. "呆在当场" == 「その場に呆然と立ち尽くし」
- **结构分析**：
  - [语法] ～に（场所限定） → [词汇] 呆然（ぼうぜん/N2，呆然）
  - [语法] ～尽くす（动作彻底） → [词汇] 立ち尽くす（たちつくす/N2，呆立）

### 2. "心里慌乱" == 「心は混乱していた」
- **结构分析**：
  - [语法] ～は（主题提示） → [词汇] 混乱（こんらん/N3，混乱）
  - [语法] ～ていた（持续状态） → [词汇] 心（こころ/N4，心里）

### 3. "一转眼就到了晚上" == 「気がつけば夜になっていた」
- **结构分析**：
  - [语法] ～ば（条件形） → [词汇] 気がつく（きがつく/N3，察觉）
  - [语法] ～になる（状态变化） → [词汇] 夜（よる/N5，晚上）

### 4. "乐得嘴都合不上了" == 「嬉しさのあまり口を閉じることができないほどだった」
- **结构分析**：
  - [语法] ～のあまり（程度过度） → [词汇] 口を閉じる（くちをとじる/N4，闭嘴）
  - [语法] ～ほど（程度表达） → [词汇] 嬉しさ（うれしさ/N4，高兴）

### 5. "心里跟吃了只苍蝇似的恶心" == 「まるで蝿を飲み込んだような嫌悪感に襲われた」
- **结构分析**：
  - [语法] まるで～よう（比喻表达） → [词汇] 蝿（はえ/N4，苍蝇）
  - [语法] ～に襲われる（被动遭遇） → [词汇] 嫌悪感（けんおかん/N2，厌恶感）

### 6. "脸上的红润都是用胭脂抹上的" == 「頬の紅はすべて紅で塗られていた」
- **结构分析**：
  - [语法] ～で（工具限定） → [词汇] 紅（べに/N3，胭脂）
  - [语法] ～ていた（持续状态） → [词汇] 塗る（ぬる/N5，涂抹）

## 心理描写注释
1. 厌恶感的表达：
   - 「蝿を飲み込んだよう」的强烈比喻
   - 日本文化中的嫌悪感程度区分

2. 妆容描写的处理：
   - 「紅」与「血色」的对比
   - 不自然妆容的暗示手法
